# Data

Machine-readable registry: [`data/sources.yaml`](../data/sources.yaml).

## Availability audit (what the paper and authors supplied)
| Item | Available? |
|---|---|
| Corpus snapshot, query set, relevance judgments | **No** |
| Feedback / click sessions, model checkpoints | **No** |
| Graph ontology, cluster configuration | **No** |
| Source code, licence for original code | **No** (this repo's code is original, MIT) |
| Aggregate results (Tables I–VI) and equations | Yes, in the paper only (PDF not redistributed) |

Consequence: the original runs cannot be re-created from the PDF. This repo provides independent data and reports measured
numbers as measured, never as a reproduction of the paper's.

## Profile 1: offline demo (synthetic)
`src/litmine/demo/` — generated by `scripts/make_demo_corpus.py`. **Original and synthetic**: no real paper, author or DOI.
DOIs use the unregistered `10.5555/litmine.syn.NNN` form. 36 records → 35 works after version-aware dedup (S12v1 superseded by S12v2).
Contains: year-stamped citations (14 resolvable), 11 labelled queries with graded qrels, hard negatives (CUSUM in traffic, changepoints in
genomics, battery capacity shifts), an ambiguous author name ("J. Park" ×3: two ORCIDs, one without), a work with no abstract (S15),
one unsupported query (q10), and train/test split + simulated feedback sessions. Demo output is **never** written to a benchmark
report (`write_ledger` skips runs whose metadata says `synthetic`; test `test_synthetic_runs_excluded_from_ledger`).

## Profile 2: SciFact (independent retrieval benchmark, BEIR format)
* Source: AllenAI SciFact (<https://github.com/allenai/scifact>), BEIR format (<https://github.com/beir-cellar/beir>). Files were
  fetched from the Hugging Face mirror `BeIR/scifact` (revision `b3b5335604bf5ee3c4447671af975ea25143d4f5`, CC-BY-SA-4.0) because the
  UKP-hosted BEIR zip reset the connection. Qrels from `BeIR/scifact-qrels`.
* Counts: 5,183 documents; 1,109 queries; released test qrels (300 queries) and train qrels (used only to tune α and train the
  policy). Document IDs are preserved verbatim.
* SHA-256: corpus.parquet `243324b3…4dc4f5`… full hashes are written into each run's `run.json`.
* **What it is:** a scientific claim-to-abstract benchmark. **What it is not:** a cited abstract may *support or refute* the claim, so
  retrieval relevance does not entail truth; it has no click log, no million-document scaling evidence and no citation network
  (so graph search and the graph ablation are *not evaluable* on it).
* Fetch: `python scripts/fetch_scifact.py` (writes `data/scifact/`, git-ignored).

## Profile 3: paper-scale workload (100K / 300K / 600K / 1M)
Bring an owner-provided or openly licensed manifest of distinct works (JSONL with an `id` field):
`litmine scale --manifest M.jsonl --state runs/scale.state`. Sampling is nested and seeded; the **actual distinct count** is recorded;
works are never cloned and passages are never counted as works. A size larger than the manifest is reported
`NOT RUNNABLE`. The runner is resumable (`mark_done`) and prints resource estimates. **No size was executed here**; no paid API or
cluster was launched.
